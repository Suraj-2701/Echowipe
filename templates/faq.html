Frequently Asked Questions

Everything you need to know about Echowipe and AI detection.

How accurate is the AI detection?
Echowipe currently maintains a 98.2% accuracy rate on clear audio samples. However, accuracy can be affected by heavy background noise or extremely low-quality recordings. We recommend using .wav files for the best results.
Which AI models can you detect?
Our system is trained to identify artifacts from major providers like ElevenLabs, OpenAI Voice, Tacotron, RVC (Retrieval-based Voice Conversion), and many open-source deepfake models.
Is my data and audio secure?
Yes. We use end-to-end encryption for all uploads. Audio files are processed in a volatile memory environment and are not stored on our servers unless you explicitly save them to your history.
Can I use the API for commercial projects?
Absolutely. Our API is designed for scale. You can integrate Echowipe into call centers, verification platforms, or content moderation tools. Check the API tab for documentation.
What file formats are supported?
We currently support .wav. For forensic-level analysis, we highly recommend uncompressed .wav files.
