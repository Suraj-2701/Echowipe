Developer API

Integrate Echowipe voice detection into your own applications with our REST API.

Base URL: http://127.0.0.1:20000
POST /api/v1/detect

Send a .wav audio file via a multipart form-data request. Our model will return the probability scores and a classification label.

Request Body

Field Type Requirement Description
audio file Required The .wav audio file to be analyzed.

Implementation Example

Python (Requests library) 
import requests

url = "http://127.0.0.1:20000/api/v1/detect"
files = {'audio': open('voice_sample.wav', 'rb')}

response = requests.post(url, files=files)
print(response.json())

Response Schema

{
  "status": "success",
  "label": "FAKE (AI GENERATED)",
  "scores": {
    "fake": 0.9852,
    "real": 0.0148
  }
}
